# Deadpool Watch 2

The sequel nobody asked for. A fan-made, fourth-wall-breaking smartwatch PWA for Nick's iPhone 15 Pro Max.
Plain HTML/CSS/JS + a tiny WebGL shader, no build step, works offline. Installs **side by side** with v1.

**Live:** https://mandeerinfinity.github.io/deadpool-watch-2/
(v1 still lives at https://mandeerinfinity.github.io/deadpool-watch/)

## Install on iPhone
1. Open the link in **Safari** → **Share** → **Add to Home Screen** → **Add**.
2. Launch **DP Watch 2** (yellow "2" badge icon).
3. Optional: **Hub → Vitals → Enable Motion** (steps, shake, tilt-driven bezel shine). **World → Use my location** for local weather.
